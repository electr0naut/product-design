## Two small fixes, as the first commit of D2

1. **Write the stored proof without following symlinks.** `recheck_stored_proofs` checks the path with
   `safe_rel_path` (which resolves it), then writes it with `write_text`. The clean worktree is under `work/prove`,
   which the container can write, so a worker could swap `tests/` for a symlink between the check and the write.
   The host would then write the proof source somewhere outside the worktree.
   - Reuse `copy_nofollow`'s component-by-component walk as `write_nofollow(root, rel, text)`, and use it here.
   - Test: a symlinked directory on the path refuses the write, the target outside is unchanged, and the result
     is `StillBroken`.
2. **Check the proofs before using up the pass.** `request_fix` writes the ledger entry, then `store_proofs` may
   raise because a proven finding has no proof source. That uses up the ticket's one pass with no cards
   created.
   - Validate every proven finding's file, id and source first; only then write the ledger.
   - Test: a missing source refuses the pass, writes no ledger entry, and the card blocks as today.
