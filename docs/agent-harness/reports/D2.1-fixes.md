## A finding about the low tier
The gates require every acceptance criterion to have a test that fails on base and passes on head. A **docs-only** ticket has no such test, so it cannot pass the gates, and a ticket that adds a test touches a path outside `docs/*` and is not low by path. In practice the low tier is reached **through labels** (`docs`, `chore`) or a path allow-list that includes tests. Question for the reviewer: should the gates learn a "docs-only ticket needs no fail-to-pass test" exemption (it would need to be deterministic: only paths in `low_risk_globs`), or do we accept label-based low?
