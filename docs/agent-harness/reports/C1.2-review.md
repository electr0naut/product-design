- **A race in the prove worktree.** The prove/refute worktrees under `work/prove/` are writable from the
  container while the host works in them. In theory a worker could swap a directory for a symlink between
  `safe_rel_path`'s check and the copy. The window is milliseconds, and the worst case is one file written
  by the host as `ubay`. If you want it closed later, copy with `os.open(..., O_NOFOLLOW)` on each path
  component, or create the prove worktrees in a host-only directory and copy only the test file into a
  container-visible one.
