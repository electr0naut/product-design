Loaded in Chromium, the landed page decodes nothing: `src/dictionary.js` imports the dictionaries as JSON modules,
browsers treat a JSON module import as a connection, and the required CSP has `connect-src 'none'`. The console
shows `Connecting to '.../src/dictionary/fix42.json' violates ... "connect-src 'none'"`, the module graph fails
to load, and the Decode button does nothing. The CSP must not change. Read technical design sections 5, 7 and 8.

`test/dictionary.test.js`, `test/render.test.js` and `test/static-checks.test.js` are expected to change in this
ticket.

Acceptance criteria
- AC0: A test imports `lookup` and `enumName` from `src/dictionary.js`, `analyse` from `src/analyse.js` and
  `render` from `src/render.js`.
- AC1: No file under `src/` imports a `.json` file. The dictionaries are JavaScript modules,
  `src/dictionary/fix42.js` and `src/dictionary/fix44.js`, each a single `export default { ... };`, generated by
  `tools/build-dictionary.mjs`. The `.json` files are removed. `lookup` and `enumName` behave exactly as before.
- AC2: The build stays reproducible: a test builds into a temporary folder and the output equals the committed
  `fix42.js` and `fix44.js` byte for byte.
- AC3: `test/static-checks.test.js` fails if any file under `src/` imports a `.json` module (static `from "...json"`
  or dynamic `import("...json")`), and passes on the delivered code.
- AC4: Each timeline row shows the message number, the event name, SendingTime (52) when present, the sender (49),
  the target (56) and MsgSeqNum (34); order events also show ClOrdID (11) and OrderID (37) when present; a
  SequenceGap also shows its detail. For
  `8=FIX.4.4|9=78|35=8|49=BROKER|56=CLIENT|34=7|52=20261126-10:00:01.000|150=0|11=CL-1|37=ORD-9|10=215|` the row's
  text contains `Message 1`, `Acknowledgement`, `20261126-10:00:01.000`, `BROKER`, `CLIENT`, `7`, `CL-1` and
  `ORD-9`.
- AC5: A message with an unsupported BeginString is rendered with its label and each field as `<tag>: <value>`,
  without any `Unknown tag` name: for `8=FIX.4.1|9=20|35=0|34=1|49=A|56=B|10=122|` the decode section contains
  `Message 1: unsupported version FIX.4.1` and `49: A`, and does not contain `Unknown tag`.
- AC6: The render tests assert the exact visible text of at least one decoded field row (`35 MsgType: A (Logon)`)
  and one timeline row.
